# SQL Joins Labs

This folder contains the SQL Joins laboratory work completed using MySQL.

## Labs Included

### Lab 8 – SQL Joins: Part A
Covers basic SQL join concepts and tasks, including:
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN using UNION
- Anti-Join
- Filtering and grouping with joins

### Lab 9 – SQL Joins: Part B & Assessment
Covers advanced join concepts and assessment tasks, including:
- SELF JOIN
- Multi-table joins
- Joins with WHERE conditions
- Joins with aggregation
- Library database assessment



## Database

**DBMS:** MySQL / MariaDB

These labs are based on the SQL Joins laboratory manual and demonstrate practical use of different SQL JOIN operations.
