## 📖 About This Repository

This repository contains my **Database Management Systems (DBMS) laboratory work**, organized according to the laboratory manuals and practical requirements.

The repository focuses on developing practical SQL skills through structured exercises involving:

- 🔗 SQL Joins
- 🔢 Scalar SQL Functions
- 📊 Aggregate Functions
- 🧩 `GROUP BY`
- 🎯 `HAVING`
- 🗂️ Database and table creation
- 🔍 Data filtering and analysis
- 📈 Practical SQL reporting
- 🧮 Calculations and data transformation

Each laboratory script contains the required **database setup, sample data, practical tasks, and assessment questions** where applicable.
