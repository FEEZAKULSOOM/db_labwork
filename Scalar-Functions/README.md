# Scalar SQL Functions Labs

This folder contains the SQL Scalar Functions laboratory work completed using MySQL/MariaDB.

## Labs Included

### Lab 10 – Part A: String Functions

This lab covers string manipulation functions from the Scalar SQL Functions manual.

Topics include:
- `TRIM()`
- `UPPER()`
- `LOWER()`
- `CHAR_LENGTH()`
- `CONCAT()`
- `SUBSTRING()`
- `LOCATE()`
- `LEFT()`
- `REPLACE()`
- `LPAD()`



### Lab 11 – Part B + Assessment

This lab covers numeric functions, date/time functions, and the Employee Database assessment.

Topics include:
- `ROUND()`
- `FLOOR()`
- `CEIL()`
- `MOD()`
- `YEAR()`
- `MONTHNAME()`
- `DAYNAME()`
- `DATE_FORMAT()`
- `TIMESTAMPDIFF()`
- `DATEDIFF()`
- `DATE_SUB()`
- `DATE_ADD()`
- Combined scalar functions

The assessment section applies these functions to an Employee Database.



## Database

**DBMS:** MySQL / MariaDB
