# Database Normalization Labs

This folder contains SQL lab work for database normalization.

## Labs Included

### Lab 4 — 1NF
Covers:
- Functional Dependencies
- Insertion, Update & Deletion Anomalies
- Conversion from Unnormalized Form to 1NF
- Creating and populating the 1NF table
- Verification queries

### Lab 5 — 2NF & 3NF
Covers:
- Partial Dependencies
- Conversion from 1NF to 2NF
- Transitive Dependencies
- Conversion from 2NF to 3NF
- Primary & Foreign Keys
- Verification and customer total-spend queries
- Reflection on anomaly prevention
