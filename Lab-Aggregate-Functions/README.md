# Aggregate SQL Functions Labs

This folder contains the SQL laboratory work for Aggregate Functions using MySQL/MariaDB.

## Labs Included

### Lab 12 – Part A: Whole-Table Aggregates & COUNT Variations

This part covers aggregate functions used to summarize data across complete tables.

Topics include:
- `COUNT(*)`
- `COUNT(col)`
- `COUNT(DISTINCT col)`
- `SUM()`
- `AVG()`
- `MIN()`
- `MAX()`
- Handling `NULL` values
- Aggregate functions with `JOIN`

File:
- `Lab12_PartA_Aggregate_Functions.sql`

---

### Lab 12 – Part B + Assessment: GROUP BY, HAVING & JOINs

This part covers grouped aggregation, filtering groups, and combining aggregate functions with joins.

Topics include:
- `GROUP BY`
- `HAVING`
- `WHERE` with `GROUP BY`
- Aggregate functions with `JOIN`
- `LEFT JOIN` with aggregates
- `ORDER BY`
- `LIMIT`
- Subqueries with aggregate functions

The assessment section uses the University Database and contains all 12 assessment questions.

File:
- `Lab12_PartB_Assessment_Aggregate_Functions.sql`
