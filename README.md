## 📖 About This Repository

This repository contains my **Database Management Systems (DBMS) laboratory work** completed as part of my Software Engineering coursework.

The repository is organized into separate laboratory folders covering fundamental and intermediate SQL concepts, database design, data manipulation, filtering, joins, scalar functions, aggregate functions, and normalization.

Each laboratory folder contains the corresponding SQL scripts, practical exercises, and supporting files required for the laboratory work.
